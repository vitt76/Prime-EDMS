## 1. EXECUTIVE SUMMARY

Это ТЗ расширяет **Часть 2** (Multi-Tenancy Infrastructure) с фокусом на **практическую интеграцию** multi-tenancy в существующие кастомные модули DAM системы:

- **DAM модуль**: AI-анализ документов, метаданные, расширенный поиск
- **Analytics модуль**: 4-уровневая иерархия метрик, real-time dashboards
- **Distribution модуль**: Share links, публикации, rendition'ы
- **Notifications модуль**: Tenant-aware уведомления через WebSocket

**Ключевая цель**: Обеспечить **100% data isolation** между тенантами при сохранении общих ресурсов (Plans, AI моделей, типов метаданных).

**Критический риск**: Миграция существующих модулей (которые разработаны **без учета multi-tenancy**) на TenantAware модель может привести к рассинхронизации данных. **Решение**: Phase-by-phase миграция с раздельными deployment флагами для каждого модуля.

**Трудоемкость:** 13-21 story points

❌ **Notifications модуль:**

- WebSocket connections не привязаны к Organization
- User-level notifications могут утечь между тенантами (если пользователь с двумя акаунтами)

**Трудоемкость:** 5-8 story points

❌ **Файловое хранилище:**

**Celery Task для AI-анализа (tenant-aware):**

```python
# mayan/apps/dam/tasks.py

from celery import shared_task
from mayan.apps.organizations.models import Organization
import logging

logger = logging.getLogger(__name__)

@shared_task(bind=True, retry_limit=3)
def analyze_document_with_ai(
    self,
    document_id: int,
    organization_id: str,  # Передаем Org ID явно
    analysis_type: str = 'ocr',
    ai_model: str = 'qwen'
):
    """
    Celery task для асинхронного AI-анализа документа.
  
    ВАЖНО: Task должна явно знать Organization ID, так как в Celery нет HTTP request контекста.
    """
    from mayan.apps.documents.models import Document
    from mayan.apps.dam.models import DocumentAIAnalysis
  
    try:
        # 1. Валидировать Organization и Document
        org = Organization.objects.get(id=organization_id)
        doc = Document.objects.get(id=document_id, organization=org)
    
        # 2. Создать запись анализа
        analysis = DocumentAIAnalysis.objects.create(
            document=doc,
            organization=org,
            analysis_type=analysis_type,
            input_file=doc.latest_file,
            ai_model=ai_model,
            status='processing'
        )
    
        # 3. Вызвать AI API (с retry, rate limiting)
        result = _call_ai_api(
            doc,
            ai_model=ai_model,
            analysis_type=analysis_type
        )
    
        # 4. Сохранить результаты
        analysis.result_data = result
        analysis.status = 'completed'
        analysis.completed_at = timezone.now()
        analysis.save()
    
        logger.info(
            f"[Org={org.slug}] Completed {analysis_type} analysis for {doc.id}",
            extra={'organization': org.id}
        )
    
    except Organization.DoesNotExist:
        logger.error(f"Organization {organization_id} not found!")
        self.retry(countdown=60, exc=Exception("Org not found"))
  
    except Exception as exc:
        analysis.status = 'failed'
        analysis.result_data = {'error': str(exc)}
        analysis.save()
        logger.error(f"AI analysis failed: {exc}", exc_info=True)
        raise

def _call_ai_api(doc, ai_model: str, analysis_type: str):
    """
    Интегрированные вызовы к различным AI модулям
    """
    # Выбрать API endpoint в зависимости от model
    if ai_model == 'qwen':
        from mayan.apps.dam.ai_providers.qwen import QwenClient
        client = QwenClient()
    elif ai_model == 'gigachat':
        from mayan.apps.dam.ai_providers.gigachat import GigaChatClient
        client = GigaChatClient()
    # ... и т.д.
  
    if analysis_type == 'ocr':
        return client.extract_text(doc.latest_file.file.path)
    elif analysis_type == 'ner':
        return client.extract_entities(doc.latest_file.file.path)
    # ... и т.д.
```

```python
# mayan/apps/notifications/consumers.py

import json
from channels.generic.websocket import AsyncWebsocketConsumer
from django.contrib.auth.models import AnonymousUser
from asgiref.sync import sync_to_async

class NotificationConsumer(AsyncWebsocketConsumer):
    """
    WebSocket consumer для real-time уведомлений.
  
    КРИТИЧЕСКИ: Проверить Organization пользователя перед отправкой данных!
    """
  
    async def connect(self):
        """
        Подключение к WebSocket.
        """
        self.user = self.scope['user']
    
        # 1. Проверить авторизацию
        if isinstance(self.user, AnonymousUser):
            await self.close()
            return
    
        # 2. Получить Organization из URL (или из токена)
        self.organization_id = self.scope['url_route']['kwargs'].get('organization_id')
    
        # 3. Валидировать, что пользователь принадлежит этой Organization
        user_org = await self._get_user_organization()
        if str(user_org.id) != self.organization_id:
            await self.close(code=4003)  # Custom code для неавторизованного доступа
            return
    
        self.organization_id = user_org.id
        self.group_name = f"notifications_{self.organization_id}_{self.user.id}"
    
        # 4. Присоединиться к группе (Channels)
        await self.channel_layer.group_add(
            self.group_name,
            self.channel_name
        )
    
        await self.accept()
        print(f"[Org={self.organization_id}] User {self.user.id} connected")
  
    async def disconnect(self, close_code):
        """Отключение от WebSocket"""
        await self.channel_layer.group_discard(
            self.group_name,
            self.channel_name
        )
  
    async def receive(self, text_data):
        """
        Получить сообщение от клиента.
        """
        data = json.loads(text_data)
        action = data.get('action')
    
        if action == 'mark_as_read':
            notification_id = data.get('notification_id')
            await self._mark_notification_read(notification_id)
    
        elif action == 'get_unread_count':
            count = await self._get_unread_count()
            await self.send(text_data=json.dumps({
                'type': 'unread_count',
                'count': count,
            }))
  
    async def send_notification(self, event):
        """
        Broadcast уведомление в group.
    
        Вызывается из Celery task: 
        channel_layer.group_send('notifications_ORG_ID_USER_ID', {...})
        """
        notification = event['notification']
    
        await self.send(text_data=json.dumps({
            'type': 'notification',
            'id': notification['id'],
            'title': notification['title'],
            'message': notification['message'],
            'created_at': notification['created_at'],
        }))
  
    @sync_to_async
    def _get_user_organization(self):
        """Получить Organization пользователя из БД"""
        from mayan.apps.organizations.models import Organization
    
        # Предположим, что у User есть связь с Organization
        # Это требует отдельной модели UserOrganizationRole
        try:
            user_org_role = self.user.userorganizationrole_set.first()
            if user_org_role:
                return user_org_role.organization
        except:
            pass
    
        raise Exception("User organization not found")
  
    @sync_to_async
    def _mark_notification_read(self, notification_id):
        """Отметить уведомление как прочитанное"""
        from mayan.apps.notifications.models import Notification
    
        notification = Notification.objects.get(
            id=notification_id,
            organization_id=self.organization_id,
            recipient=self.user
        )
        notification.is_read = True
        notification.save()
  
    @sync_to_async
    def _get_unread_count(self):
        """Получить количество непрочитанных уведомлений"""
        from mayan.apps.notifications.models import Notification
    
        return Notification.objects.filter(
            organization_id=self.organization_id,
            recipient=self.user,
            is_read=False
        ).count()
```

# Cursor Rules для DAM Project — Multi-Tenancy Integration

## Context
- Backend: Django 3.2, Python 3.9, PostgreSQL, Redis, Celery
- Frontend: Vue 3 + TypeScript, Nuxt 3
- Project: Mayan EDMS с кастомными модулями (DAM, Analytics, Distribution, Notifications)
- Scope: Интеграция multi-tenancy в существующие модули

## Key Architectures
1. **TenantAwareMixin**: Все tenant-aware модели наследуют Organization FK
2. **TenantAwareManager**: Автоматическая фильтрация QuerySet по request.organization
3. **TenantResolverMiddleware**: Определение Org по домену/поддомену/токену
4. **Async Tasks**: Celery передает organization_id явно (нет HTTP request context)

## Critical Rules
1. **Security First**: Никогда не вызывай `.objects_unfiltered` без явной проверки SuperAdmin
2. **No N+1 Queries**: Используй select_related() / prefetch_related() для FK/reverse FK
3. **Idempotent**: Все Celery tasks должны быть идемпотентны (могут запуститься дважды)
4. **Indexing**: Добавляй index на (organization_id, timestamp) для performance
5. **WebSocket Security**: Всегда валидировать Organization в WebSocket connect()

## Code Patterns

### Tenant-Aware Models
```python
from mayan.apps.organizations.models import TenantAwareMixin

class MyModel(TenantAwareMixin, models.Model):
    # organization поле добавляется из миксина
    title = models.CharField(max_length=255)
  
    class Meta:
        indexes = [
            models.Index(fields=['organization', '-created_at']),
        ]
```

### QuerySets

```python
# ✅ GOOD: Автоматическая фильтрация по Organization
docs = Document.objects.all()  # Только текущей org

# ❌ BAD: Небезопасно
docs = Document.objects_unfiltered.all()  # Все документы!

# ✅ GOOD: Явная фильтрация для super admin
if request.user.is_superuser:
    docs = Document.objects_unfiltered.all()
```

### Celery Tasks

```python
@shared_task
def my_async_task(organization_id: str, data: dict):
    """Всегда передавай organization_id явно"""
    org = Organization.objects.get(id=organization_id)

```

```python
    def get_queryset(self):
        org = self.request.organization  # Из Middleware
        return MyModel.objects.filter(organization=org)  # Redundant but explicit
```
