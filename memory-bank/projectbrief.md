# Project Brief: Prime-EDMS

## Обзор проекта

**Prime-EDMS** — это система управления цифровыми активами (Digital Asset Management, DAM) на базе открытой платформы Mayan EDMS версии 4.3.1. Проект представляет собой расширенную адаптацию системы управления электронными документами для работы с медиа-контентом с интеллектуальной обработкой через AI-провайдеры.

## Основные цели

1. **Управление цифровыми активами**: Централизованное хранение, организация и управление медиа-файлами (изображения, видео, документы)
2. **AI-обогащение метаданных**: Автоматическое извлечение метаданных через множественные AI-провайдеры (YandexGPT, GigaChat, OpenAI, Claude, Gemini, Qwen Local, KieAI)
3. **Интеграция с российскими сервисами**: Поддержка интеграции с Яндекс.Диск для импорта файлов и использование российских AI-сервисов
4. **Современный фронтенд**: Vue 3 SPA с TypeScript (основной DAM UI) и отдельный публичный сайт на Nuxt 3 (`public-frontend/`) для маркетинга, лидов и входа в продукт
5. **Масштабируемость**: Архитектура на базе Docker с поддержкой горизонтального масштабирования через Celery workers

## Основной функционал

### Backend (Mayan EDMS)
- Управление документами и версионирование
- AI-анализ документов с автоматическим извлечением метаданных (теги, описания, категории, люди, локации, цвета)
- REST API v4 для интеграций
- Система прав доступа (ACL) и ролей
- OCR распознавание текста
- Полнотекстовый поиск с поддержкой JSON-полей через GIN индексы
- Workflow и состояния документов
- Аналитика использования активов

### Frontend
- Vue 3 SPA с TypeScript (`frontend/`, Vite)
- Nuxt 3 публичный контур (`public-frontend/`)
- Интеграция с REST API через токен-аутентификацию (SPA) и публичные `/api/v4/public/*` (сайт)
- Автоматическое заполнение учетных данных при первом запуске
- Управление цифровыми активами через современный UI

### Интеграции
- **Яндекс.Диск**: Импорт файлов из облачного хранилища
- **S3 Storage (Beget)**: Хранение файлов в облачном хранилище
- **AI-провайдеры**: Множественные провайдеры для анализа контента

## Целевая аудитория

Система предназначена для организаций, которым требуется:
- Централизованное управление медиа-контентом
- Автоматическая категоризация и тегирование через AI
- Соответствие требованиям ФЗ-152 (работа с персональными данными)
- Интеграция с российскими сервисами

## Технические требования

- **ОС**: Ubuntu 20.04+ или Windows 10/11 с WSL2
- **Минимум**: 4GB RAM, 10GB свободного места
- **База данных**: PostgreSQL 12.10+
- **Кэш/Очереди**: Redis 6.2+, RabbitMQ 3.10+
- **Python**: 3.9
- **Django**: 3.2.14

## Статус проекта

Проект находится в активной разработке с фокусом на:
- Расширение AI-функциональности
- Улучшение аналитики использования активов
- Интеграция с внешними системами
- Оптимизация производительности поиска и обработки
